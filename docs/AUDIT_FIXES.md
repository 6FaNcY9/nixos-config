## Batch 1 — Dead Code & Nix Correctness (safe, no behaviour change)

### 1.1 Remove `lib.mkDefault` no-op on `repoRoot` in flake.nix
**File**: `flake.nix` around line 131
**Problem**: `lib.mkDefault` is a NixOS module system function — it has no effect at flake level.
**Fix**: Change:
```nix
repoRoot = lib.mkDefault "/home/${username}/src/nixos-config";
```
to:
```nix
repoRoot = "/home/${username}/src/nixos-config";
```

### 1.2 Remove redundant `// { default = false; }` on `mkEnableOption`
**File**: `nixos-modules/features/services/auto-update.nix` around line 20
**Problem**: `lib.mkEnableOption` already defaults to `false`. Overriding it is a no-op.
**Fix**: Change:
```nix
timer.enable = lib.mkEnableOption "systemd timer for automatic updates" // { default = false; };
```
to:
```nix
timer.enable = lib.mkEnableOption "systemd timer for automatic updates";
```

### 1.3 Remove dead `pkgs.unstable.claude-code` branch
**File**: `home-modules/profiles.nix` around line 26
**Problem**: No `pkgs.unstable` overlay or attribute exists in this repo. The branch is always skipped.
**Fix**: Find the block that tries `pkgs.unstable.claude-code` then falls back to `pkgs.claude-code`. Remove the `pkgs.unstable` attempt and just use `pkgs.claude-code` (or `pkgs.claude-code or null`).

### 1.4 Move `pkgs.snapper` out of core packages
**File**: `nixos-modules/core/packages.nix`
**Problem**: `pkgs.snapper` is in the always-on core package list, but snapper is a feature with its own enable flag.
**Fix**: Remove `pkgs.snapper` from `nixos-modules/core/packages.nix` and add it inside `nixos-modules/features/storage/snapper.nix` within the `config = lib.mkIf cfg.enable { environment.systemPackages = [ pkgs.snapper ]; }` block.

### 1.5 Fix `validateSecretEncrypted` heuristic
**File**: `lib/default.nix` around line 37
**Problem**: Checks for the string `"sops"` which is too weak — any file mentioning the word "sops" passes. Should check for the actual SOPS ciphertext prefix.
**Fix**: Replace the check for `"sops"` with a check for `"ENC[AES256_GCM"` which is the actual prefix of SOPS-encrypted values.

### 1.6 Fix dead `passwordFile == null` warning in backup module
**File**: `nixos-modules/features/services/backup.nix` around line 117
**Problem**: `passwordFile` is typed as `lib.types.path` (non-nullable, required), so `== null` can never be true.
**Fix**: Change the `passwordFile` option type from `lib.types.path` to `lib.types.nullOr lib.types.path` with `default = null;`. Then add an assertion:
```nix
assertions = lib.mapAttrsToList (name: repoCfg: {
  assertion = repoCfg.passwordFile != null;
  message = "backup repository '${name}' requires passwordFile to be set";
}) cfg.repositories;
```

### 1.7 Fix `deadnix -f` in QA script (modifies files silently)
**File**: `flake-modules/scripts/qa.sh`
**Problem**: `deadnix -f .` in the QA script silently rewrites Nix files in-place before the user reviews changes. `-f` means "fix mode".
**Fix**: Remove the `-f` flag. Change `deadnix -f .` to `deadnix .` in `qa.sh` (report only, don't modify). Do the same in `flake-modules/scripts/commit.sh` if it also uses `deadnix -f`.

## Batch 2 — Security Hardening (additive, no breakage risk)

### 2.1 Add missing SSH hardening settings
**File**: `nixos-modules/features/services/openssh.nix`
**Problem**: Several critical SSH settings are missing from the module defaults.
**Fix**: Add these to `services.openssh.settings` inside the `config = lib.mkIf cfg.enable { ... }` block:
```nix
services.openssh.settings = {
  MaxAuthTries = lib.mkDefault 3;
  LoginGraceTime = lib.mkDefault 30;
  ClientAliveInterval = lib.mkDefault 300;
  ClientAliveCountMax = lib.mkDefault 2;
  AllowTcpForwarding = lib.mkDefault "no";
  LogLevel = lib.mkDefault "VERBOSE";
};
```
Also fix the `permitRootLogin` option type from `lib.types.str` to:
```nix
lib.types.enum [ "yes" "no" "prohibit-password" "forced-commands-only" ]
```
And add an assertion blocking the dangerous combo:
```nix
assertions = [{
  assertion = !(cfg.passwordAuthentication && cfg.permitRootLogin == "yes");
  message = "openssh: PermitRootLogin=yes with PasswordAuthentication=true is a critical security risk";
}];
```

### 2.2 Add `kernel.yama.ptrace_scope` to desktop hardening
**File**: `nixos-modules/features/security/desktop-hardening.nix`
**Problem**: Default ptrace_scope=0 allows any process to attach to any other process owned by the same user, enabling memory reads of GPG agent, SSH agent, etc.
**Fix**: Add to the `boot.kernel.sysctl` block:
```nix
"kernel.yama.ptrace_scope" = 1;
```

### 2.3 Add IPv6 redirect protection to server hardening
**File**: `nixos-modules/features/security/server-hardening.nix`
**Problem**: IPv4 redirect protection is set but IPv6 equivalents are missing.
**Fix**: Add to the `boot.kernel.sysctl` block:
```nix
"net.ipv6.conf.all.accept_redirects" = 0;
"net.ipv6.conf.default.accept_redirects" = 0;
```

### 2.4 Set explicit fail2ban ban parameters
**File**: `nixos-modules/features/security/server-hardening.nix`
**Problem**: fail2ban `maxretry`/`bantime`/`findtime` are left at upstream defaults (5 retries, 10 min ban). Need explicit values.
**Fix**: In the `services.fail2ban.jails.sshd` definition, add:
```nix
settings = {
  maxretry = 3;
  bantime = 86400;  # 24 hours
  findtime = 600;
};
```
(Check exact fail2ban NixOS option path — it may be under `services.fail2ban.jails.sshd.settings` or as string config.)

### 2.5 Change firewall to DROP (not REJECT) on desktop
**File**: `nixos-modules/features/security/desktop-hardening.nix` around line 117
**Problem**: `rejectPackets = lib.mkDefault true` sends TCP RST/ICMP replies, disclosing host presence on untrusted networks.
**Fix**: Change to `rejectPackets = lib.mkDefault false;` (DROP semantics).

### 2.6 Add assertion: server-hardening requires openssh enabled
**File**: `nixos-modules/features/security/server-hardening.nix`
**Problem**: The fail2ban sshd jail is activated even if openssh is not enabled, making it protect a port that isn't open.
**Fix**: Add to `config = lib.mkIf cfg.enable { ... }`:
```nix
assertions = [{
  assertion = config.features.services.openssh.enable;
  message = "features.security.server-hardening requires features.services.openssh.enable = true for the sshd fail2ban jail to be effective";
}];
```

## Batch 3 — Architecture Fixes

### 3.1 Fix cfgLib inline imports in nixos-modules
**Files**:
- `nixos-modules/features/hardware/laptop.nix` line ~12
- `nixos-modules/features/development/base.nix` line ~12
- `nixos-modules/features/security/secrets.nix` line ~14

**Problem**: Each of these modules independently does `import ../../../lib { inherit lib; }`. The home-modules side injects `cfgLib` via `_module.args` once and all modules receive it as a function arg. The nixos side doesn't do this.

**Fix**:
1. In `nixos-modules/default.nix` or the nixos-modules root, add:
```nix
_module.args.cfgLib = import ../lib { inherit lib; };
```
2. Then in each of the three modules, change the inline import to just accept `cfgLib` as a function argument:
```nix
{ config, lib, cfgLib, ... }:
```
And remove the `let cfgLib = import ../../../lib { inherit lib; }; in` line.

### 3.2 Fix dunst font hardcoded string
**File**: `home-modules/features/desktop/services.nix` around line 28
**Problem**: Font is hardcoded as `"IosevkaTerm Nerd Font 10"` instead of using the `stylixFonts` argument that's available in rofi and other desktop modules.
**Fix**:
1. Add `stylixFonts` as a function argument to the module (same as how rofi/default.nix receives it).
2. Replace the hardcoded string with `"${stylixFonts.monospace.name} 10"`.
Check how `stylixFonts` is injected (likely via `_module.args` in `home-configurations/vino/default.nix`) and add `services.nix` to receive it.

### 3.3 Fix workspace lookup to use number attribute
**File**: `home-modules/features/desktop/i3/workspace.nix` around line 11
**Problem**: `builtins.elemAt workspaces (n - 1)` looks up workspace by list position. If `shared-modules/workspaces.nix` list order changes, wrong workspace gets the wrong name silently.
**Fix**: Replace with a lookup by the `number` attribute:
```nix
wsName = n: (lib.findFirst (ws: ws.number == n) (throw "workspace ${toString n} not found") workspaces).name;
```
(Check actual workspace attrset structure in `shared-modules/workspaces.nix` first.)

### 3.4 Set device options for bandit host
**File**: `home-configurations/vino/hosts/bandit.nix`
**Problem**: `devices.battery`, `devices.backlight`, and `devices.networkInterface` default to `""` (empty string), causing polybar to silently omit battery, brightness, and network modules for the bandit host.
**Fix**: Read `home-modules/core/devices.nix` for the option names. Then in `home-configurations/vino/hosts/bandit.nix` set:
```nix
devices.battery = "BAT1";        # Framework 13 battery device
devices.backlight = "amdgpu_bl1"; # AMD GPU backlight (already used in polybar/modules.nix)
devices.networkInterface = "wlp1s0"; # Verify with: ip link show
```
Verify actual device names by checking `nixos-configurations/bandit/default.nix` for hints or checking the hardware.

## Batch 4 — Script & Docs Fixes

### 4.1 Fix rofi scripts using hardcoded theme paths
**Files**:
- `home-modules/features/desktop/rofi/scripts/audio-switcher.sh` line ~16
- `home-modules/features/desktop/rofi/scripts/dropdown-menu.sh` lines ~44, 55, 71

**Problem**: Both scripts reference `~/.config/rofi/<theme>.rasi` as a hardcoded path. Other scripts (network-menu.sh, power-menu.sh) use `-theme <name>` which lets rofi resolve the theme via its configured path. Using the hardcoded path breaks if `$HOME` is unusual and bypasses Nix management.

**Fix for audio-switcher.sh**: Change `-theme ~/.config/rofi/audio-switcher-theme.rasi` to `-theme audio-switcher-theme`

**Fix for dropdown-menu.sh**: Change all occurrences of `-theme ~/.config/rofi/dropdown-theme.rasi` to `-theme dropdown-theme`

### 5.4 Remove per-step `nix-collect-garbage` in cachix.yml

**Fix**: Remove the `nix-collect-garbage` calls between steps. Add a single GC at the very end of the job if disk space is still a concern: `nix store gc --max-freed 10G`.
